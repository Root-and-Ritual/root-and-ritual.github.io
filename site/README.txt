ROOT & RITUAL — VERSION 7

INSTALL
Back up the current site folder. Extract this ZIP and upload all its contents together into root&ritual, preserving the assets folder. Entry: index.html. Main: root-and-ritual.html. No build or external packages required. Outer Domain links to ../index.html.

CONTENTS
201 dossiers across 31 domains. Original 33 records retained. Added 42 reference dossiers: vampires and werewolves; Irish banshee, puca, dullahan and leprechaun; mermaid/merman and merrow; Bermuda Triangle; 12 Greek gods/goddesses and 6 Greek creatures; 12 Egyptian gods/goddesses and 3 Egyptian creatures.

PAGES
Entrance, Sanctorum, domain directory, searchable ledger, individual dossiers, original lore library, start guide, organization guide, handbook, glossary, folklore/mythology guide, and sources.

BACKGROUND AND FICTION
New reference dossiers link to consulted background sources. Invented Root & Ritual story premises are separate and marked as draft fiction. Reference entries have Unassigned threat / Reference only status. The traditional banshee is separate from the invented Bramble Banshee. Egyptian sphinx imagery is not merged with the Greek sphinx. These are introductory selections, not exhaustive pantheons. Historical sources may contain outdated language; the old lore page is preserved as unverified project notes.

DATABASE
root_and_ritual_db.csv: complete 201-record v7 download.
root_and_ritual_db_original.csv: unchanged original 33-record upload.
assets/data.js: live display database, including expanded dossiers and source links.
When editing records, update the display database and CSV together. Counts and domain options in HTML are static and should also be updated when records change.

FUNCTIONS
Full-record search, exact domain and threat filters, clear filters, CSV export of visible records, empty and missing-record states, and related dossiers. Source links require internet access; the rest of the site works from bundled files.

ACCESS
The entrance is ceremonial and provides no authentication. The original password form did not validate a password. Configure hosting-level protection across the folder and assets if the archive should be private.

VALIDATION
Checked JavaScript syntax, all 201 dossier rendering paths, search and category behavior, empty/reset states, internal file links, record uniqueness, CSV counts, and ZIP integrity. Visual browser verification remains outstanding.
